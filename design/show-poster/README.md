# Show poster — Last Comp

Three A4 directions for a poster to stand on the table at a card show. Built
from the site's own tokens (`apps/public/app/globals.css`) rather than
approximated: same ground, same accent, same Archivo Expanded file the iOS
launch image uses.

| artboard | what it is | trade-off |
|---|---|---|
| `Main.dc.html` | Dark, the brand as it is. Argues its case: an example answer, three claims, then the code. | An A4 of near-black drinks ink and prints streaky on a desktop printer. |
| `Paper.dc.html` | Same argument on paper — one flat teal block instead of a full-bleed dark ground. Survives a black-and-white photocopy. | Less arresting from a distance. |
| `ScanFirst.dc.html` | For an aisle rather than a table: one instruction, one code, readable across a hall. | Says almost nothing about what the site does. |

```
node design/show-poster/build.mjs        # rebuild the artboards and previews
node design/show-poster/shot.mjs Main    # screenshot one, needs playwright
```

`build.mjs` is the only place any of this is written down. Three hand-kept
files would drift, and the drift is exactly the kind nobody sees until a
hundred of them are printed: a wordmark set two ways, or two posters on the
same table quoting different figures for the same card.

**Fonts are embedded as woff2 data URIs, not linked.** The canvas can pull
Google Fonts at view time, but its PNG/PDF export cannot embed them — an
exported poster silently falls back to Arial, and for a piece whose whole
identity is Archivo at width 125% that is the failure that matters. `fonts.css`
is generated: Archivo is subset from `apps/public/assets/Archivo-Expanded-800.ttf`,
the rest from the same Google faces `layout.js` self-hosts. Regenerate it only
if the glyph set needs to grow (see the `--unicodes` range in the commit that
added it) — `build.mjs` reads it as-is.

**Everything on the poster is something the site actually does.** The claims,
the 90-day window, the graded line: a poster for a product whose proposition is
that it shows its working cannot carry a claim the site can't back. The example
row is marked as an example, and the figures are the Umbreon VMAX 215/203 case
that `CLAUDE.md` already documents.

`qr.json` is the code for `https://www.lastcomp.co.uk`, drawn as vector paths so
it stays sharp at any print size. It is checked against segno's own matrix rather
than eyeballed — a QR that scans to the wrong place is invisible on a proof.

The canvas itself (`last-comp-show-poster.html`) is regenerated by seeding these
artboards, so it is not committed.
